# Oficina online · descargas

Aquí se publican los instaladores de **Oficina online**. El código es privado; esta página solo contiene las versiones para descargar.

**[Ir a la última versión](https://github.com/dap0ry/oficina-online-releases/releases/latest)**

## Instalación

| Sistema | Archivo | Cómo |
| --- | --- | --- |
| macOS (Apple Silicon: M1 o más nuevo) | `…_darwin-aarch64.dmg` | Abre el `.dmg` y arrastra la app a Aplicaciones. |
| macOS (Intel) | `…_darwin-x86_64.dmg` | Igual que arriba. |
| Windows 10/11 | `…_windows-x86_64.exe` | Doble clic. Se instala solo para tu usuario, sin pedir permisos de administrador. |
| Linux | `…_linux-x86_64.AppImage` o `.deb` | AppImage: `chmod +x` y ejecutar. Deb: `sudo apt install ./archivo.deb`. |

### macOS: primera vez

La app aún no está firmada con un certificado de Apple. Si macOS dice que no se puede abrir, haz clic derecho sobre la app, elige **Abrir** y confirma. Solo hace falta la primera vez.

### Windows: SmartScreen

Si aparece «Windows protegió tu PC», pulsa **Más información** y luego **Ejecutar de todas formas**.

## Actualizaciones

No tienes que volver aquí: la app busca versiones nuevas al arrancar y cada hora, las descarga en segundo plano y se reinicia sola cuando no estás ocupado (con un aviso de 10 segundos y un botón «Más tarde»). Tus datos y tu sesión se conservan.
